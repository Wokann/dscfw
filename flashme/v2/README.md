# FlashMe V2 Phat reconstruction

[中文说明](README.zh-cn.md)

This armips package reconstructs the FlashMe V2 Phat
layout from Nintendo retail <code>official_v3.bin</code>. The recovered FlashMe image is a
verification reference only; it is never a build input.

> This is an inferred functional reconstruction. No original V2 image is available as a byte-level reference, so its output must not be presented as a recovered or byte-identical historical image.

## Inputs and tools

- Put <code>official_v3.bin</code> in the <code>flashme/</code> root directory.
- The package uses <code>../../tools/armips/armips.exe</code> and
  <code>../../tools/dsfwtool/dsfwtool.exe</code> for nested V7/V8 packages, or the
  corresponding parent-relative paths defined by this package's <code>Makefile</code>.
- <code>temp/</code> holds plaintext H/P1–P5 exported from the Nintendo retail input.
  <code>build/</code> holds the plaintext replacement components generated by armips.

## Build

~~~sh
make
~~~

The final <code>dsfwtool</code> call recomputes component metadata, applies the required
compression/encryption, places components at the exact offsets specified in
<code>Makefile</code>, fills the image to 256 KiB, and preserves the applicable settings
region from the Nintendo retail input.

## Outputs and validation

The build verifies the Nintendo base image before unpacking. It then writes a
UTF-8 CRC record beside each result and checks the FlashMe CRC-16/IBM range
<code>[0x000000, 0x3FDFE)</code> against the recovered-reference value.

| Variant | Output | CRC record | Reference CRC-16 |
| --- | --- | --- | --- |
| <code>normal</code> | <code>flashme_v2_phat.bin</code> | <code>flashme_v2_phat.crc16</code> | <code>0x3A90</code> |

<code>normal</code> has no variant suffix. <code>stealth</code>, <code>noauto</code>, and <code>stealth_noauto</code>
appear after the model in the output name. The Makefile spelling
<code>stealth-noauto</code> selects the <code>stealth_noauto</code> output variant.

## Reconstruction model

The package first exports decrypted/decompressed retail components with
<code>dsfwtool</code>, applies the armips patches under <code>src/</code>, then packs H/P1–P5/FH/FP1/
FP2 back into one firmware image. The source files, generated component layout,
and all variant-specific addresses are kept local to this package; <code>Makefile</code>
is the authoritative description of the ROM placement.
