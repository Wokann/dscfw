# FlashMe V7 Old Lite 存档说明

[English](README.md)

本目录刻意不保留源码、Makefile、构建输出或 CRC 记录。

## 版本状态

已知 V7 Lite 存在 beta 1 与 beta 2，但此前收录于此的独立安装镜像暂无法确认究竟属于哪一个 beta。

已验证：该独立安装镜像中的 Lite 固件，与 V7 Lite 及 Phat 集成安装包内置的 Lite 固件完全相同。因此它可能是 beta 2，
但这仍是推测，并非已确认结论。

由于固件相同，本仓库不再独立维护 V7 Old Lite 的源码/构建副本。请前往
[`flashme/v7_new/lite/README.zh-cn.md`](../../v7_new/lite/README.zh-cn.md)
查看持续维护的 Lite 代码与分析。
